Almost ready — connect the backend

This app stores cycles in a free Supabase database so your whole family sees the same data. One-time setup, about 5 minutes.

  1. Go to supabase.com, sign up, and click New Project. Give it a name and a database password, pick the closest region, and wait for it to finish setting up.
  2. Open the SQL Editor (left sidebar) → New query. Paste the script below and press Run. This creates the tables.
  3. Go to Project Settings → Data API (or API). Copy the Project URL and the anon / public key.
  4. Open index.html in VS Code. Near the top, paste the URL into SUPABASE_URL and the key into SUPABASE_ANON_KEY. Set your APP_PIN.
  5. Push to GitHub and deploy on Vercel. Share the link + PIN with your family. Done!
-- Paste this whole block into Supabase SQL Editor, then Run create table if not exists cycles ( id text primary key, cycle_number int not null, chemo_date text not null, note text default '', created_at timestamptz default now() ); create table if not exists visits ( id text primary key, visit_date text not null, title text default '', symptoms text default '', questions text default '', created_at timestamptz default now() ); create table if not exists contacts ( id text primary key, name text not null, phone text not null, category text default 'other', note text default '', created_at timestamptz default now() ); create table if not exists vitals ( id text primary key, reading_date text not null, bp_sys int, bp_dia int, sugar text default '', temp text default '', note text default '', created_at timestamptz default now() ); create table if not exists issues ( id text primary key, issue_date text not null, text text not null, created_at timestamptz default now() ); alter table cycles enable row level security; alter table visits enable row level security; alter table contacts enable row level security; alter table vitals enable row level security; alter table issues enable row level security; create policy "open_all_cycles" on cycles for all using (true) with check (true); create policy "open_all_visits" on visits for all using (true) with check (true); create policy "open_all_contacts" on contacts for all using (true) with check (true); create policy "open_all_vitals" on vitals for all using (true) with check (true); create policy "open_all_issues" on issues for all using (true) with check (true);

Schedule settings

Defaults follow the standard R-CHOP rhythm. Change only if your doctor uses a different interval. (Applies on this device.)

The fever-watch window (days 7–14 after chemo) is when white-cell counts dip lowest and infection risk is highest. During it, a temperature of 100.4°F (38°C) or above should be treated as urgent — contact the doctor or hospital straight away.
